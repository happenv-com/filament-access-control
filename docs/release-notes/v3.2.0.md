## v3.2.0

### Features

- **The role picker.** A list icon next to the matrix's search opens every role with a checkbox, a search and *Select all* / *Deselect all*; the choice is kept for the session, the table says how many roles it shows while some are hidden, and a role added from the page is shown straight away. `->rolesShownByDefault(8)` shows the first roles only until the operator picks others (unset, every role shows as before); `->deferRolePicker(false)` applies every tick at once instead of on Apply. Both on the plugin and on `PermissionMatrix`. Built from Filament's table filters — it narrows the columns, never the rows.
- **The matrix keeps its bearings while it scrolls.** The permission column stays at the frame's start while the roles scroll past it, and the row of role names stays at the top while the permissions scroll under it — the frame scrolls both ways, capped at the viewport's height. Filament has no sticky table columns, so this is the package's first stylesheet: plain CSS on Filament's classes, confined to the matrix, published by `php artisan filament:assets` (which `filament:upgrade` runs).

### Fixes

- A table wider than the page scrolls inside its own frame instead of stretching the page past the viewport (also in v3.1.2).
