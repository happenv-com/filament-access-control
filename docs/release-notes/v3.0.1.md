## v3.0.1

### Fixes

- Every role cell names itself for assistive technology again: next to its icon sits a screen-reader-only text — the cell's tooltip, or its state — as Filament's `IconColumn` adds on its own. It also names the button of a clickable cell.
- The *Dependencies* column stays hidden on a screen narrowed to a surface when none of that surface's permissions declares a rule or a condition.
- `dependencies.related` (shown for a rule type a future laravel-access-control minor might add) is translated in every shipped locale.
